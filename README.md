🧮 Calc

A simple, clean calculator application built with pure HTML, CSS and JavaScript — perfect for embedding in webpages, learning JavaScript, or using as a utility in projects.

🖥️ Overview

Calc provides a user-friendly calculator interface that performs basic arithmetic operations (addition, subtraction, multiplication, division) and possibly more (if implemented).
You can use it to:

Perform quick calculations in the browser.

Embed or adapt it in your own web projects.

Study the JavaScript logic of a calculator — how input parsing, display update and event handling work.

🚀 Features

✅ Built with vanilla JavaScript, no frameworks or libraries required.

🧮 Basic arithmetic operations supported (and easily extendable).

💡 Responsive, minimal UI — works on desktops and mobile devices.

🧠 Straightforward code structure: easy to read, modify, and extend.

🎯 Ready to integrate or embed into other web pages.

# 1. Clone the repository
git clone https://github.com/iamyoussefezzat/calc.git

# 2. Open the app in a browser
open index.html

├── index.html         # Main HTML file
├── styles.css         # CSS styling for calculator UI
├── script.js          # JavaScript logic for operations
├── assets/            # (optional) images or icons
│   └── screenshot.png
└── README.md          # This documentation

🧩 How to Use / Customize

Use the calculator directly by clicking the buttons or typing (if enabled).

To add more operations, edit script.js and implement new handlers (e.g., modulus, exponentiation, memory functions).

Customize styling by modifying styles.css — change theme colors, button shapes, animations.

To embed the calculator in another webpage, you can copy index.html markup and include the relevant CSS/JS.

🔧 Future Enhancements

Add scientific functions (sin, cos, tan, log, etc.).

Support keyboard input in addition to button clicks.

Store calculation history and allow recall of previous results.

Add dark/light mode themes or user selection.

Make it into a mobile-friendly PWA (Progressive Web App) for offline usage.
